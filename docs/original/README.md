# Materiale originale

Questa cartella conserva le scansioni fornite come fonte primaria per l'implementazione.

## Regolamenti

- `Regolamento Originale.pdf`: regolamento del gioco base in quattro lingue, 11 pagine.
- `Regolamento Originale 2.pdf`: espansione originale Zargo's Lords 2, 5 pagine.

## Ruote

Le quattro fotografie mostrano i due lati delle ruote originali:

- frecce e fiamme;
- combattimento;
- calendario con riferimenti per frecce e fiamme;
- calendario con riferimenti per visioni e fasce di combattimento.

I file HEIC sono gli originali. Le copie JPEG sono incluse per la consultazione diretta su GitHub.
